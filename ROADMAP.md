# Drawsie content roadmap

Tutorial subjects kids (ages 3–15) like, all at **10 steps or fewer**.
Step counts below include the final color panel, matching how the site
counts (the cat is "8 steps").

Age bands:
- **Ages 3–5** — "First drawings": 5–6 steps, basic shapes only.
- **Ages 6–9** — the core library: 7–8 steps, simple details.
- **Ages 10–15** — 9–10 steps, cooler subjects, more detail steps.

Status: ✅ live · 🔜 in the first batch · blank = planned.

## Production rules

- **Variants multiply the library:** a popular subject gets 2–3 variants
  (different pose/direction/scene), each its own tutorial + folder
  (see AGENTS.md — peer folders, never nested).
- **Seasonal timing:** holiday subjects ship 3–4 weeks before the holiday;
  teachers and parents search on a schedule.
- **No copyrighted characters** (no Pikachu, Bluey, Hello Kitty…). Generic
  equivalents only — baby dragon, cute robot, etc.
- House style is the approved cute/chibi vector style; every tutorial is
  cumulative vector step data (see AGENTS.md).
